# Companion mission gold

Mission returns consolidate loose gold in the companion shared pack after rewards are recorded. This applies to AFK, offline, and ordinary returns, and combines existing piles as well as newly earned gold. Each stack remains at or below 60,000. Gold inside separate bags and gold with different names, hues, or loot flags is preserved separately.

The previous AFK/offline delivery used direct container insertion, bypassing ordinary stacking. Consolidation now occurs after journal receipts so old gold is not counted as newly earned rewards.

Validation: full content suite, 1,108 tests. Tests cover an actual AFK mission return with preexisting gold and exact report totals, stack limits, quantity conservation, separate nested bags, differently colored gold, and repeated consolidation.

# Island home travel

`[home` and the island chart now explain the actual reason when travel is unavailable: wrong character, death, criminal flag, unfinished spell, PvP travel cooldown, a restricted departure area, or an obstructed/restricted landing. An unfinished spell target can be canceled with Escape before retrying.

Ownership, travel restrictions, the island landing search, and pet transport are preserved. Read-only release status includes each character's `HomeTravel` result using the same checks without teleporting the character.
